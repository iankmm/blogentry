I'll be joining [Exa](https://exa.ai/) to work with the infra and security team full time starting this year and I wanted to leave a few notes on my belief on the current state of llms and how Exa indefinitely expands their capabilities. 



Simply put, the web was built for us (humans), but the models need something else. llm models have been exponentially improving in the past couple of years, but they're only as good as the information they can access. Traditional search engines, like Google, that we use as humans, return ranked pages with a lot of noise, and what these models actually need is a semantic retrieval engine with structured content and programmatic access for their context system. This is exactly what Exa is building. An infrastructure that redefines how software interacts with the internet.



It's becoming clearer as these models improve that model intelligence is becoming a negligible factor when benchmarking them, but context is. You can simply scale parameters or fine tune these models, but if the fundamental information that they have access to is incomplete or outdated, then the output directly reflects that noise. Hence, artificial intelligence without high-quality retrieval of information is very fragile. 



With autonomous agents, models aren't simply asking questions but they're operating on behalf of the user, and if you've previously worked on mcp servers or agents in general, then you know how important search context is to these systems.



In many different ways, this honestly feels like working on the next generation of a networking layer of the early internet for agents. If we are able to get retrieval right, the entire categories of llm native applications become very feasible.



So yeah! Very excited to work with them, and if anyone in SF wants to connect and meet up, lmk :)
